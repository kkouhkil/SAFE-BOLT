# Setup

1. Keep your existing repository `.git` directory if replacing an existing checkout.
2. Copy this package's files into the repository root.
3. Confirm the logo exists at `assets/img/branding/ut_austin_primary.png`.
4. Run `bundle install` once.
5. Run `bundle exec jekyll serve` for local preview.
6. Commit and push only after the local preview looks correct.

Do not edit `_site/`; Jekyll generates it automatically.
